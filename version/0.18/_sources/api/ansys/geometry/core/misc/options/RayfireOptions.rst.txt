





:class:`RayfireOptions`
=======================


.. py:class:: ansys.geometry.core.misc.options.RayfireOptions(radius: ansys.geometry.core.misc.measurements.Distance | pint.Quantity | ansys.geometry.core.typing.Real, direction: ansys.geometry.core.math.vector.UnitVector3D, max_distance: ansys.geometry.core.misc.measurements.Distance | pint.Quantity | ansys.geometry.core.typing.Real, min_distance: ansys.geometry.core.misc.measurements.Distance | pint.Quantity | ansys.geometry.core.typing.Real, tight_tolerance: bool = False, pick_back_faces: bool = False, max_hits: int = 0, request_params: bool = False, request_secondary: bool = False)

   
   Additional options for ray fire operations.


   :Parameters:

       **radius** : :obj:`Distance` | :obj:`Quantity` | :obj:`Real`
           The radius of the ray.
           If a Real is provided, it is assumed to be in the default length unit.

       **direction** : :obj:`UnitVector3D`
           The direction for the ray to be fired in.

       **max_distance** : :obj:`Distance` | :obj:`Quantity` | :obj:`Real`
           The maximum distance the ray should travel.
           If a Real is provided, it is assumed to be in the default length unit.

       **min_distance** : :obj:`Distance` | :obj:`Quantity` | :obj:`Real`
           The minimum distance the ray should travel.
           If a Real is provided, it is assumed to be in the default length unit.

       **tight_tolerance** : :ref:`bool <python:bltin-boolean-values>`, default=False
           Whether to use a tight tolerance for the ray fire operation.

       **pick_back_faces** : :ref:`bool <python:bltin-boolean-values>`, default=False
           Whether to pick back faces during the ray fire operation.

       **max_hits** : :class:`python:int`, default=0
           The maximum number of hits the ray should register.

       **request_params** : :ref:`bool <python:bltin-boolean-values>`, default=False
           Whether to request additional parameters for the ray fire operation.

       **request_secondary** : :ref:`bool <python:bltin-boolean-values>`, default=False
           Whether to request secondary hits for the ray fire operation.
